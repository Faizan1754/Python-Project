# Python Intern Task – Fetch Users from Public API

## 📋 Task Description
This script fetches user data from the public API:
https://jsonplaceholder.typicode.com/users

It displays each user’s:
- Name  
- Username  
- Email  
- City  

### 🧩 Bonus
You can also filter users whose city name starts with the letter **'S'**.

---

## ⚙️ How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/python-intern-task.git
   cd python-intern-task
   ```

2. Install dependencies:
   ```bash
   pip install requests
   ```

3. Run the script:
   ```bash
   python fetch_users.py
   ```

4. For bonus version:
   ```bash
   python fetch_users_bonus.py
   ```
